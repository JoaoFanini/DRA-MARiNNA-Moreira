# Dra. Marinna Moreira — prévia do site

React + Vite · GSAP · Lenis. Estrutura base reescrita para consultório odontológico.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # gera dist/
```

Onde editar: `src/data/content.js` (contatos, horários, tratamentos, passos). Cores: `src/styles/tokens.css`. Itens marcados como "a confirmar" precisam de dados reais da doutora antes do envio final.
